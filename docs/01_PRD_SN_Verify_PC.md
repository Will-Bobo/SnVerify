# 01_PRD_SN_Verify_PC.md

## 一、核心目标

通过一次扫码触发完整校验流程，确保：

SN_Scan == SN_ADB → PASS
SN_Scan != SN_ADB / 超时 → NG

## 二、核心需求

### 1. 输入管理

* 支持扫码枪模拟键盘输入
* SN 由字母 + 数字构成
* 不区分大小写，忽略首尾空格

### 2. 原子化校验流程

* 扫码即触发校验
* 校验过程中禁止再次输入
* 单次流程结束前，所有新输入丢弃

### 3. ADB 读取规则

* 使用 ADB 命令读取设备序列号（具体命令待预研确认，如 `adb shell getprop ro.serialno`）
* 超时时间：10 秒
* 失败允许重试 3 次，间隔 1 秒

### 4. 判定规则

* 字符串完全匹配 → PASS
* 不匹配 / 超时 → NG
* 忽略首尾空格，不区分大小写

### 5. MES 交互

* 支持工位准入检查
* 支持测试结果上报
* MES 异常需本地缓存，后续补传

### 6. UI 行为

* 等待状态 → 扫码
* 处理中 → Loading / 进度提示
* 结束状态 → PASS / NG 明确展示
