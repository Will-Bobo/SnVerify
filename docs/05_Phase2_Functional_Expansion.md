# 05_Phase2_Functional_Expansion.md

## Phase 2 目标

在 Phase 1 技术闭环验证通过的基础上，补齐工程化与产线可用性能力，使系统可长期稳定运行于真实生产环境。

## Phase 2 功能范围

### 1. ADB 能力增强

* 明确并固化设备 SN 的读取命令
* 支持设备未连接 / 多设备连接的识别与提示
* 增加 ADB 异常分类日志

### 2. MES 可靠性增强

* MES 接口失败后的本地缓存与补传机制
* 支持断网 / 弱网场景
* 明确事务一致性策略（最终一致性）

### 3. 日志与数据治理

* 日志分级（INFO / WARN / ERROR）
* 日志自动压缩与清理策略
* 按批次导出 CSV 报表

### 4. UI 与可用性

* 更明确的 PASS / NG 视觉反馈
* 操作员误操作提示优化
* 异常弹窗节流，避免频繁打断产线操作

## Phase 2 不包含

* 权限系统
* 用户管理
* 云端部署或多工位协同

## Phase 2 交付标准

* 连续运行稳定（长时间不重启）
* 异常可追溯（日志 + 数据）
* 满足产线节拍要求
