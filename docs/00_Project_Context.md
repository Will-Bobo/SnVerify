# 00_Project_Context.md

## 一、项目背景

在产线测试环境中，Android 设备存在外壳条码与设备内部序列号不一致的风险。为避免错码、混码流入后续工序或市场，需要在指定工位通过上位机软件进行强一致性校验。

SnVerify 上位机用于解决以下问题：

* 确保每一台设备的外壳 SN 与设备内部 SN 100% 一致
* 防止人工误操作或重复扫码
* 将校验结果实时同步至 MES 系统

## 二、使用场景

* Windows 工控机 / 普通 PC
* USB 扫码枪（模拟键盘输入）
* Android 设备通过 USB 连接（ADB 通讯）
* 有网络环境，可访问 MES 接口

## 三、范围界定（本项目关心的）

* SN 的一致性校验结果（PASS / NG）
* MES 接口的调用与异常处理
* 本地日志与报表导出

## 四、非目标（明确不做的事情）

* 不参与产线工艺决策
* 不处理 NG 后的人工流程
* 不管理设备固件、刷机或升级
* 不承担 MES 之外的数据同步责任
