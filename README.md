# README.md

## 项目名称

SnVerify（上位机）

## 项目简介

SnVerify 是一套运行于 Windows（支持 Windows 7 及以上）的上位机软件，用于生产线场景下对 Android 设备进行序列号一致性校验。

软件通过 **扫码枪输入的外壳条码 SN（SN_Scan）** 与 **通过 ADB 从设备读取的内部序列号（SN_ADB）** 进行比对，只有在两者完全一致时，设备才允许通过当前工位，并将结果上传至杰科 MES 系统，形成生产测试闭环。

## 项目目标

* 单扫码触发、单设备处理
* 原子化校验流程（防误触、防并发）
* 明确 PASS / NG 判定
* MES 接口闭环对接
* 本地日志与批次报表导出

## 开发方式

* 人员配置：1 人 + AI（Cursor Agent 深度参与）
* 技术框架：WPF / .NET Framework 4.x
* 开发原则：TDD、最小闭环优先、需求文档驱动
